# おえかき（oekaki）

小さな子ども向けの、タブレットで指を使って絵を描くための Web アプリです。
HTML ファイル 1 つ（`index.html`）だけで動き、インストールやビルドは不要です。

主な対象は iPad（Safari）で、iPhone や PC のブラウザでも使えます。

## 特徴

- **何本の指でも同時に描ける**：マルチタッチに対応しています。きょうだいや親子で一緒に描けます。
- **8 色＋消しゴム**：あか・オレンジ・きいろ・みどり・あお・むらさき・ピンク・くろ。
- **誤操作に強い**
  - 「ぜんぶ消す」は 1 秒の長押しでだけ働きます。うっかりタップしても絵は消えません。
  - ピンチによる拡大縮小、ダブルタップでの拡大、長押しメニュー、画面のスクロールを止めています。
  - パレットのボタンに触れても、その下のキャンバスには線が引かれません。
- **画面を回転しても絵が残る**：向きを変えると、描いた絵が新しい画面サイズに合わせて伸び縮みします。
- **いろいろな画面サイズに対応**：iPad、iPhone の縦と横、iPad の Slide Over で、すべてのボタンが画面内に収まります。ボタンの大きさは 44px 以上を保ちます。
- **外部への通信なし**：外部のライブラリやフォント、解析ツールは読み込みません。描いた絵がどこかに送られることもありません。

## 使い方

### 画面の見かた

画面のほぼ全体が画用紙（キャンバス）です。下の中央にパレットがあります。

| ボタン | 動作 |
| --- | --- |
| 色のしずく（8 色） | タップすると、その色で描けるようになります。選ばれている色は少し大きく、傾いて表示されます。 |
| 点線の丸（消しゴム） | タップすると、なぞった部分を消せるようになります（太めの消しゴムです）。 |
| ごみ箱 | **1 秒長押し**すると、絵を全部消します。押している間はボタンの周りに赤い輪が伸びます。輪が一周する前に指を離すか、指をボタンの外へずらすと、取り消されます。 |

### 描きかた

- 指でなぞると線が引けます。タップすると点が残ります。
- 起動したときは「あか」が選ばれています。
- 線を描いている途中で別の指で色を変えても、描いている途中の線の色は変わりません。新しく描き始めた線から、新しい色になります。
- PC ではマウスでも描けます（動作確認用です）。

### 知っておいてほしいこと

- **描いた絵は保存されません。** ページを再読み込みしたり閉じたりすると消えます。残したいときは、端末のスクリーンショット機能を使ってください。
- 「元に戻す」機能はありません。
- 画面を回転すると、絵は新しい縦横比に合わせて引き伸ばされます。

## 起動方法

### いちばん手軽な方法

`index.html` をブラウザで開くだけで使えます。

### iPad・iPhone で使う（おすすめ）

1. `index.html` を Web サーバーに置き、端末の Safari から開けるようにします。下の「Web に公開する」を参照してください。
2. Safari でページを開きます。
3. 共有ボタン →「ホーム画面に追加」を選びます。
4. ホーム画面に追加された「おえかき」アイコンから起動すると、アドレスバーのない全画面表示になります。

#### 小さな子どもに渡すときのおすすめ設定

ホームボタンやスワイプでアプリから出てしまわないように、iPad の **アクセスガイド** を使うと安心です。

1. 「設定」→「アクセシビリティ」→「アクセスガイド」をオンにします。
2. おえかきを起動してから、サイドボタン（またはホームボタン）を 3 回押すと、アクセスガイドが始まります。

### 同じネットワークの端末から試す（開発・動作確認向け）

PC でリポジトリのフォルダに移動し、簡易サーバーを起動します。

```sh
# Python がある場合
python3 -m http.server 8000

# Node.js がある場合
npx serve .
```

同じ Wi-Fi に接続した iPad の Safari で `http://<PC の IP アドレス>:8000/` を開きます。

### Web に公開する

ファイルは `index.html` の 1 つだけなので、静的ファイルを置ける場所ならどこでも公開できます。

- **GitHub Pages**：リポジトリの Settings → Pages で、公開元に `main` ブランチのルート（`/`）を選びます。数分後に `https://<ユーザー名>.github.io/oekaki/` で開けるようになります。
- そのほか、Netlify、Cloudflare Pages、社内の Web サーバーなどに `index.html` を置くだけでも動きます。

## 対応環境

| 環境 | 状況 |
| --- | --- |
| iPad（Safari） | 主な対象です。 |
| iPhone（Safari） | 使えます。縦向きの画面ではパレットが 2 段になります。 |
| Android のブラウザ（Chrome など） | タッチイベントで動く作りなので使えるはずですが、自動テストの対象外です。 |
| PC のブラウザ（Chrome、Edge、Safari、Firefox） | マウスで描けます（1 本だけ）。 |

自動テストは、Chromium で iPad や iPhone の画面を再現して行っています。実機の Safari での動作も確認したうえで使ってください。

## カスタマイズ

設定はすべて `index.html` の中の `<script>` の先頭近くにまとまっています。

| 変えたいもの | 場所 | 初期値 |
| --- | --- | --- |
| 色 | `COLORS` 配列 | 8 色 |
| 線の太さ | `BRUSH` | `17`（CSS ピクセル） |
| 消しゴムの太さ | `ERASER_SIZE` | `46` |
| 画用紙の色 | `PAPER`（JavaScript）と、CSS の `--paper` | `#FFF9F0` |
| 「ぜんぶ消す」の長押し時間 | `HOLD_MS` | `1000`（ミリ秒） |
| 長押し中、指がボタンの外へずれても許す幅 | `HOLD_SLOP` | `16`（CSS ピクセル） |
| パレットのボタンの直径 | CSS の `--btn` | `58px`（小さい画面では 44〜48px） |

> **注意**
> - 画用紙の色を変えるときは、`PAPER` と `--paper` の**両方**を同じ値にしてください。消しゴムは画用紙の色で塗りつぶす仕組みなので、値がずれると消した跡が見えてしまいます。
> - 色の数を変えると、パレットの幅が変わります。iPhone の縦向きではボタンを 5 列に並べる設定（CSS の `grid-template-columns: repeat(5, ...)`）なので、必要に応じて列の数も調整してください。
> - 変更したあとは、下の自動テストを実行してください。色や太さを変えると、その値を前提にしたテストが失敗します。そのときはテスト側の期待値（`tests/oekaki.test.js` の先頭にある `RED`、`BLUE` など）も合わせて直してください。

## 自動テスト

[Playwright](https://playwright.dev/) で Chromium を動かし、アプリの動作を自動で確認するテストがあります。

### 必要なもの

- Node.js（LTS 版をおすすめします。動作確認は v22 で行っています）

### 実行手順

```sh
npm install                       # Playwright をインストール
npx playwright install chromium   # テスト用の Chromium をダウンロード（最初の 1 回だけ）
npm test
```

成功すると、最後に次のように表示されます。どれか 1 つでも失敗すると、終了コードは `1` になります。

```
==== 結果: 14/14 Pass ====
```

テスト中に撮ったスクリーンショットは `tests/artifacts/` に保存されます（Git の管理対象外です）。

### テストの内容

iPad Pro 11 インチ相当（1194×834、デバイスピクセル比 2、タッチ対応）の画面でページを開きます。マルチタッチの操作を再現し、キャンバスの特定の座標のピクセルの色を読み取って確かめます。

| No. | 確認すること |
| --- | --- |
| 1 | 起動時にコンソールエラーがなく、画面全体が画用紙の色であること |
| 2 | タップで初期色（あか）の点が残ること |
| 3 | 3 本の指で同時に別々の線が引けること。ピンチしても拡大されずに描けること |
| 4 | 色を切り替えると、その色で描けること。選択表示が 1 つだけであること |
| 5 | 描いている途中で色を変えても、その線の色は変わらないこと |
| 6 | 消しゴムが決まった太さで消すこと |
| 7 | 「ぜんぶ消す」が短い押下では働かず、長押しで働くこと |
| 8 | 画面の向きやサイズが変わっても絵が残ること |
| 9 | 拡大やスクロールを止める設定（CSS・meta タグ）が入っていること |
| 10 | パレットに触れても、下のキャンバスに線が引かれないこと |
| 11 | 2 本の指での誤操作（交互に叩く、途中で指を離すなど）で「ぜんぶ消す」が働かないこと |
| 12 | 長押し中に指をボタンの外へずらすと取り消されること |
| 13 | マウスでの誤操作（右ボタンなど）で「ぜんぶ消す」が働かないこと |
| 14 | 20 種類の画面サイズで、すべてのボタンが画面内に収まり、押せて、44px 以上あること |

## ファイル構成

```
.
├── index.html             # アプリ本体（HTML・CSS・JavaScript をすべて含む）
├── package.json           # テスト用の設定（npm test）
├── package-lock.json
└── tests/
    └── oekaki.test.js     # Playwright による自動テスト
```

アプリを動かすのに必要なのは `index.html` だけです。それ以外のファイルはテスト用です。
